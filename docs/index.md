## Overview

pcke scans your repository, extracts knowledge (modules, entities, relations,
annotations), and stores everything in an embedded B+tree database with WAL
durability, full-text search, and a query DSL.

It integrates with AI assistants via:

- **Context files** generated by `pcke sync` (Markdown for Copilot, Cursor, etc.)
- **MCP server** via `pcke serve` (stdio transport, tools + resources)
- **CLI queries** via `pcke query`, `pcke recall`, `pcke explain`, `pcke export`
